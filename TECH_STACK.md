# 🛠️ Z-CARD - Tech Stack

## 💻 Frontend Core
- **React 19**: A última palavra em interfaces reativas.
- **Vite 8**: Para um desenvolvimento veloz como um Aston Martin.
- **React Router 7**: Gestão de rotas sofisticada.

## 🎨 Design & UI
- **Tailwind CSS 4**: Estilização moderna e eficiente.
- **Lucide React**: Ícones minimalistas e expressivos.
- **Framer Motion**: Animações fluidas para uma experiência premium.
- **Recharts**: Visualização de dados para dashboards.

## ⚙️ Backend & Infra
- **Supabase**: Nosso motor de banco de dados (PostgreSQL), autenticação e storage.
- **Firebase**: FCM (Firebase Cloud Messaging) para notificações push.
- **Asaas API**: Gestão financeira com sistema de toggle Sandbox/Produção centralizado em `supabase/functions/_shared/asaas-config.ts`.

## 📱 Mobile & PWA
- **Vite Plugin PWA**: Transformando nossa web app em uma experiência quase nativa.
- **QR Code Tools**: `html5-qrcode` e `qrcode.react` para a ponte entre o físico e o digital.

## 🚀 Deployment
- **Vercel**: Hospedagem de alta performance com CI/CD.
